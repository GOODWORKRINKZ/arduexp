# arduexp - Синтезатор на библиотеке Mozzi для Arduino UNO

Экспериментальный проект синтезатора для Arduino UNO с использованием библиотеки Mozzi для высококачественного синтеза звука.

## Описание

Этот проект представляет собой полноценный цифровой синтезатор с возможностью выбора инструментов (тембров). С помощью 7 кнопок вы можете играть ноты (C, D, E, F, G, A, B), а дополнительная кнопка позволяет переключаться между 4 различными инструментами с уникальными звуковыми характеристиками.

## Возможности

- 🎹 **7 нот** - полная октава от C до B
- 🎺 **4 инструмента** с различными тембрами:
  - **Синусоида** - чистый тон, похожий на флейту
  - **Пила** - яркий, резкий звук аналогового синтезатора
  - **Меандр** - полый звук, похожий на кларнет
  - **Треугольник** - мягкий звук, похожий на виолончель
- 🔊 Высококачественный синтез звука через библиотеку Mozzi
- 🎛️ Быстрое переключение между инструментами одной кнопкой
- ⚡ Низкая латентность - мгновенный отклик на нажатие кнопок

## Подключение оборудования

### Необходимые компоненты:
- Arduino UNO (или совместимая плата)
- 8x Кнопки (тактовые кнопки)
- 1x Динамик или наушники (8 Ом)
- 1x Резистор 100 Ом (для аудио выхода)
- 1x Конденсатор 10 мкФ (для аудио выхода, опционально)
- Макетная плата и провода

### Схема подключения:

#### Кнопки нот:
```
Arduino Pin 8 -- Кнопка C -- GND
Arduino Pin 7 -- Кнопка D -- GND
Arduino Pin 6 -- Кнопка E -- GND
Arduino Pin 5 -- Кнопка F -- GND
Arduino Pin 4 -- Кнопка G -- GND
Arduino Pin 3 -- Кнопка A -- GND
Arduino Pin 2 -- Кнопка B -- GND
```

#### Кнопка выбора инструмента:
```
Arduino Pin 9 -- Кнопка выбора -- GND
```

#### Аудио выход:
```
Arduino Pin 9 -- [100Ω] -- [+ Динамик -] -- GND
                    |
                 [10µF]  (опционально, для лучшего качества)
```

Подробная схема находится в файле [WIRING.md](WIRING.md).

**Примечание:** Arduino использует встроенные подтягивающие резисторы (INPUT_PULLUP), поэтому кнопки подключаются напрямую к GND.

## Установка и запуск

### Требования:
- [PlatformIO](https://platformio.org/) (установка через pip: `pip install platformio`)

### Сборка проекта:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/GOODWORKRINKZ/arduexp.git
cd arduexp
```

2. Соберите проект:
```bash
platformio run
```

3. Загрузите в Arduino (подключите плату через USB):
```bash
platformio run --target upload
```

## Использование

После загрузки программы в Arduino, подключите динамик или наушники к аудио выходу (пин 9).

### Как играть:

1. **Выбор инструмента**: 
   - Нажимайте кнопку выбора инструмента (пин 9) для переключения между тембрами
   - Доступны 4 инструмента: Синусоида → Пила → Меандр → Треугольник → (цикл повторяется)

2. **Игра нот**: 
   - Нажимайте кнопки нот (пины 2-8) для воспроизведения звука
   - Каждая кнопка соответствует ноте: C, D, E, F, G, A, B

3. **Создание музыки**: 
   - Экспериментируйте с разными инструментами
   - Попробуйте сыграть простые мелодии
   - Комбинируйте разные тембры для интересных эффектов

### Характеристики инструментов:

| Инструмент | Характер звука | Похож на |
|------------|----------------|----------|
| Синусоида | Чистый, мягкий тон | Флейта |
| Пила | Яркий, резкий, богатый | Аналоговый синтезатор |
| Меандр | Полый, носовой | Кларнет |
| Треугольник | Мягкий, тёплый | Виолончель |

## Как это работает

Проект использует библиотеку **Mozzi** - мощную библиотеку для генерации звука на Arduino:

- **Волновые таблицы** - предварительно рассчитанные формы волн для разных инструментов
- **Осцилляторы** - генерируют звук на основе волновых таблиц
- **PWM (ШИМ)** - Arduino генерирует высококачественный аудио сигнал через пин 9
- **Низкая латентность** - время отклика менее 10 мс

Mozzi работает на частоте 16384 Гц (AUDIO_RATE) и опрашивает кнопки 64 раза в секунду (CONTROL_RATE).

## Калибровка

Если звук слишком тихий или громкий, вы можете изменить резистор на аудио выходе:

```
- Слишком тихо: уменьшите резистор (47-100 Ом)
- Слишком громко: увеличьте резистор (220-470 Ом)
```

Для подключения наушников рекомендуется использовать резистор 220 Ом.

## Устранение неполадок

1. **Звука нет:**
   - Проверьте подключение динамика/наушников
   - Убедитесь, что код загружен в Arduino
   - Проверьте резистор на аудио выходе

2. **Кнопки не работают:**
   - Проверьте подключение кнопок к правильным пинам
   - Убедитесь, что кнопки подключены к GND
   - Проверьте качество контактов на макетной плате

3. **Звук искажен или шипит:**
   - Добавьте конденсатор 10 мкФ на аудио выход
   - Проверьте качество динамика/наушников
   - Убедитесь, что Arduino получает стабильное питание

4. **Кнопка выбора инструмента срабатывает несколько раз:**
   - Это нормально для дешёвых кнопок (дребезг контактов)
   - В коде реализован антидребезг с задержкой 200 мс
   - Можно увеличить DEBOUNCE_DELAY в коде для более медленного переключения
