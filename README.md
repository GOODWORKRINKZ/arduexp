# arduexp - Полифонический проект с двумя бузерами

Экспериментальный проект для Arduino UNO с двумя бузерами для воспроизведения полифонической музыки.

## Описание

Этот проект демонстрирует возможность создания полифонической музыки с использованием двух пьезо-бузеров, подключённых к Arduino UNO. Каждый бузер играет свою партию мелодии, создавая богатое звучание с гармониями и аккомпанементом.

## Возможности

- 🎵 Полифоническое воспроизведение (два независимых голоса)
- 🎹 Три встроенные мелодии:
  - Jingle Bells (Колокольчики)
  - Happy Birthday (С днём рождения)
  - Ode to Joy (Ода к радости - Бетховен)
- 🎛️ Управление через Serial Monitor
- 🔄 Автоматический повтор мелодий
- 🎚️ Легко расширяемый для добавления новых мелодий

## Подключение оборудования

### Необходимые компоненты:
- Arduino UNO (или совместимая плата)
- 2x Пьезо-бузеры (активные или пассивные)
- 2x Резисторы 100 Ом (рекомендуется)
- Макетная плата и провода

### Схема подключения:
```
Arduino UNO Pin 9  --[100Ω]-- Бузер 1 (+) -- GND
Arduino UNO Pin 10 --[100Ω]-- Бузер 2 (+) -- GND
```

**Примечание:** Резисторы помогают защитить пины Arduino и снижают громкость. Можно использовать резисторы 100-330 Ом.

## Установка и запуск

### Требования:
- [PlatformIO](https://platformio.org/) (установка через pip: `pip install platformio`)

### Сборка проекта:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/GOODWORKRINKZ/arduexp.git
cd arduexp
```

2. Соберите проект:
```bash
platformio run
```

3. Загрузите в Arduino (подключите плату через USB):
```bash
platformio run --target upload
```

4. Откройте Serial Monitor для управления:
```bash
platformio device monitor
```

## Использование

После загрузки программы в Arduino, откройте Serial Monitor (скорость 9600 бод). 

### Команды:
- `1` - Запустить мелодию "Jingle Bells"
- `2` - Запустить мелодию "Happy Birthday"
- `3` - Запустить мелодию "Ode to Joy"
- `s` - Остановить воспроизведение

При запуске автоматически начинается воспроизведение "Jingle Bells".

## Как это работает

Проект использует функцию Arduino `tone()` для генерации звука на каждом из двух пинов. Каждый бузер управляется независимо:

- **Бузер 1** играет основную мелодию (верхний голос)
- **Бузер 2** играет аккомпанемент (басовая линия или гармонии)

Синхронизация достигается через использование таймеров `millis()`, что позволяет обоим бузерам играть одновременно без блокировки выполнения.

## Добавление новых мелодий

Чтобы добавить свою мелодию:

1. Определите ноты и длительности в массивах `Note`:
```cpp
Note myMelody[] = {
  {NOTE_C4, 250}, {NOTE_E4, 250}, {NOTE_G4, 500},
  // ...
};
```

2. Добавьте обработку в функцию `startMelody()`

3. Обновите список команд в Serial Monitor
