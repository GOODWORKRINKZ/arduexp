# arduexp - Интерактивный музыкальный проект с фоторезисторами

Экспериментальный проект для Arduino UNO, создающий музыку с помощью двух фоторезисторов и одного бузера.

## Описание

Этот проект демонстрирует возможность создания интерактивной музыки с использованием фоторезисторов. Изменяя количество света, попадающего на сенсоры, вы можете управлять нотами и их длительностью, создавая уникальные мелодии в реальном времени.

## Возможности

- 🎵 Интерактивное управление звуком через свет
- 🎹 22 доступные ноты (от C3 до C6)
- 🎚️ Два канала управления:
  - Фоторезистор 1 - выбор ноты (частоты)
  - Фоторезистор 2 - длительность интервала (50-1000 мс)
- 📊 Вывод данных в Serial Monitor для отладки
- 🔄 Неблокирующий код - плавное управление звуком
- 🎛️ Сглаживание показаний для стабильной работы

## Подключение оборудования

### Необходимые компоненты:
- Arduino UNO (или совместимая плата)
- 1x Пьезо-бузер (пассивный)
- 2x Фоторезисторы (5-10 кОм при обычном освещении)
- 2x Резисторы 10 кОм (для делителя напряжения)
- 1x Резистор 100 Ом (для бузера, опционально)
- Макетная плата и провода

### Схема подключения:

#### Бузер:
```
Arduino Pin 9 --[100Ω]-- Бузер (+) -- GND
```

#### Фоторезисторы (делитель напряжения):
```
Фоторезистор 1:
+5V -- Фоторезистор -- A0 -- Резистор 10кОм -- GND

Фоторезистор 2:
+5V -- Фоторезистор -- A1 -- Резистор 10кОм -- GND
```

Подробная схема находится в файле [WIRING.md](WIRING.md).

**Примечание:** Фоторезисторы образуют делители напряжения - при большем освещении напряжение на аналоговом входе увеличивается.

## Установка и запуск

### Требования:
- [PlatformIO](https://platformio.org/) (установка через pip: `pip install platformio`)

### Сборка проекта:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/GOODWORKRINKZ/arduexp.git
cd arduexp
```

2. Соберите проект:
```bash
platformio run
```

3. Загрузите в Arduino (подключите плату через USB):
```bash
platformio run --target upload
```

4. Откройте Serial Monitor для управления:
```bash
platformio device monitor
```

## Использование

После загрузки программы в Arduino, откройте Serial Monitor (скорость 9600 бод) для просмотра текущих значений.

### Как играть:
1. **Управление нотой**: Изменяйте освещённость первого фоторезистора (A0)
   - Больше света = более высокая нота
   - Меньше света = более низкая нота

2. **Управление длительностью**: Изменяйте освещённость второго фоторезистора (A1)
   - Больше света = более длинные ноты (до 1 секунды)
   - Меньше света = более короткие ноты (от 50 мс)

3. **Создание музыки**: 
   - Закрывайте и открывайте фоторезисторы руками или предметами
   - Экспериментируйте с различными комбинациями
   - Используйте ритмичные движения для создания мелодий

### Данные в Serial Monitor:
```
Фоторезистор1: 512 | Нота: 440 Гц | Фоторезистор2: 768 | Длительность: 500 мс
```

## Как это работает

Проект использует аналоговые входы Arduino для чтения показаний фоторезисторов:

- **Фоторезистор 1 (A0)** - значение от 0 до 1023 преобразуется в одну из 22 нот
- **Фоторезистор 2 (A1)** - значение от 0 до 1023 преобразуется в длительность 50-1000 мс

Код использует неблокирующий подход с функцией `millis()`, что позволяет плавно менять параметры звука без задержек. Показания сенсоров сглаживаются для более стабильного звучания.

## Калибровка

Если диапазон нот или длительностей вас не устраивает, вы можете изменить параметры в коде:

```cpp
// Изменить диапазон длительности (по умолчанию 50-1000 мс)
int mapToDuration(int photoValue) {
  return map(photoValue, 0, 1023, 50, 1000);  // Измените 50 и 1000
}

// Количество семплов для сглаживания (по умолчанию 5)
const int SMOOTH_SAMPLES = 5;  // Увеличьте для более плавной работы
```

## Устранение неполадок

1. **Звука нет:**
   - Проверьте полярность бузера
   - Убедитесь, что используете пассивный бузер
   - Проверьте подключение пина 9

2. **Фоторезисторы не работают:**
   - Проверьте делители напряжения (резисторы 10 кОм должны быть на месте)
   - Откройте Serial Monitor - там должны меняться значения
   - Попробуйте закрыть/открыть фоторезисторы рукой

3. **Звук нестабильный:**
   - Увеличьте SMOOTH_SAMPLES в коде для большего сглаживания
   - Проверьте качество соединений на макетной плате
