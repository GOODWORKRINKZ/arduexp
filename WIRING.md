# Схема подключения к Arduino UNO

## Подключение компонентов

```
           Arduino UNO
         ┌──────────────┐
         │              │
         │  Digital 9───┼───[ 100Ω ]───┬─── Buzzer (+)
         │              │               │
         │              │               └─── Buzzer (-)───┐
         │              │                                  │
         │  Analog A0───┼────┬─── Фоторезистор 1          │
         │              │    │                             │
         │  +5V      ───┼────┴─── Фоторезистор 1          │
         │              │                                  │
         │  Analog A1───┼────┬─── Фоторезистор 2          │
         │              │    │                             │
         │  +5V      ───┼────┴─── Фоторезистор 2          │
         │              │                                  │
         │  GND      ───┼──────┬───[ 10kΩ ]──┬────────────┘
         │              │      │             │
         └──────────────┘      └────────── A0
                               │
                               └───[ 10kΩ ]──── A1
```

## Детальная схема фоторезисторов (делитель напряжения)

### Фоторезистор 1 (управление нотой - A0):
```
        +5V
         │
         ├─── Фоторезистор 1
         │
    A0 ──┤
         │
         ├─── Резистор 10 кОм
         │
        GND
```

### Фоторезистор 2 (управление длительностью - A1):
```
        +5V
         │
         ├─── Фоторезистор 2
         │
    A1 ──┤
         │
         ├─── Резистор 10 кОм
         │
        GND
```

### Бузер:
```
Digital Pin 9 ──[ 100Ω ]── Buzzer (+)
                            │
                           GND
```

## Примечания

1. **Резисторы:**
   - **10 кОм** для делителей напряжения фоторезисторов (обязательны)
   - **100 Ом** для бузера (опционально, но рекомендуется)
   - Резистор для бузера защищает пин Arduino и снижает громкость

2. **Типы фоторезисторов:**
   - Лучше всего подходят фоторезисторы 5-10 кОм при обычном освещении
   - Типичные модели: GL5528, GL5537, GL5539
   - Полярности у фоторезисторов нет - можно подключать любой стороной

3. **Типы бузеров:**
   - **Пассивные пьезо-бузеры** - оптимальный выбор для этого проекта
   - **Активные бузеры** - не подойдут, т.к. не могут менять частоту

4. **Полярность бузера:**
   - Обычно красный/длинный вывод = (+), чёрный/короткий = (-)
   - Если бузер не издаёт звук, попробуйте поменять полярность

5. **Тестирование:**
   - Сначала подключите только бузер и проверьте звук
   - Затем добавьте первый фоторезистор (A0)
   - После успешной проверки добавьте второй (A1)
   - Откройте Serial Monitor для просмотра показаний сенсоров

## Делитель напряжения - как это работает

Фоторезистор меняет своё сопротивление в зависимости от освещения:
- **Яркий свет**: сопротивление уменьшается → напряжение на A0/A1 увеличивается
- **Темнота**: сопротивление увеличивается → напряжение на A0/A1 уменьшается

Arduino измеряет это напряжение (0-5V) и преобразует в число 0-1023.

## Выбор резисторов для делителя

Резистор 10 кОм хорошо работает с большинством фоторезисторов. Но вы можете подобрать оптимальное значение:

- Если диапазон изменений слишком мал → используйте резистор ближе к среднему сопротивлению вашего фоторезистора
- Для фоторезисторов 5-10 кОм → используйте 4.7-10 кОм
- Для фоторезисторов 10-50 кОм → используйте 10-22 кОм

## Питание

Arduino UNO получает питание через:
- USB кабель (от компьютера)
- Внешний блок питания 7-12V (через разъём питания)

**Примечание:** Бузеры потребляют очень мало энергии, USB питания достаточно.
