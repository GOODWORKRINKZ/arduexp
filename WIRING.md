# Схема подключения бузеров к Arduino UNO

## Подключение компонентов

```
        Arduino UNO
      ┌──────────────┐
      │              │
      │  Digital Pin │
      │      9    ───┼───[ 100Ω ]───┬─── Buzzer 1 (+)
      │              │               │
      │  Digital Pin │               └─── Buzzer 1 (-)───┐
      │     10    ───┼───[ 100Ω ]───┬─── Buzzer 2 (+)    │
      │              │               │                     │
      │              │               └─── Buzzer 2 (-)────┤
      │              │                                     │
      │     GND   ───┼─────────────────────────────────────┘
      │              │
      └──────────────┘
```

## Альтернативная схема (без резисторов)

Если у вас высокоомные бузеры (например, пьезо-элементы), можно подключить напрямую:

```
Arduino Pin 9  ────── Buzzer 1 (+) ────┐
                                       │
Arduino Pin 10 ────── Buzzer 2 (+) ────┤
                                       │
Arduino GND    ───────────────────────────┘
```

## Примечания

1. **Резисторы (рекомендуется):**
   - Защищают пины Arduino от перегрузки
   - Снижают громкость до комфортного уровня
   - Рекомендуемый диапазон: 100-330 Ом

2. **Типы бузеров:**
   - **Пассивные пьезо-бузеры** - лучший выбор для этого проекта
   - **Активные бузеры** - будут работать, но с ограниченным диапазоном тонов

3. **Полярность:**
   - Обычно красный провод = (+), чёрный = (-)
   - Если бузер не издаёт звук, попробуйте поменять полярность

4. **Тестирование:**
   - Сначала подключите один бузер для проверки
   - Затем добавьте второй бузер
   - При правильном подключении вы услышите две ноты одновременно

## Питание

Arduino UNO получает питание через:
- USB кабель (от компьютера)
- Внешний блок питания 7-12V (через разъём питания)

**Примечание:** Бузеры потребляют очень мало энергии, USB питания достаточно.
