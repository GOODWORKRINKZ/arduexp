# Схема подключения к Arduino UNO

## Подключение компонентов

```
           Arduino UNO
         ┌──────────────┐
         │              │
         │  Digital 9───┼───[ 100Ω ]───┬─── Аудио выход (+)
         │              │               │
         │              │            [10µF]  (опционально)
         │              │               │
         │              │               └─── Динамик/Наушники
         │              │                                  │
         │  Digital 8───┼────┬─── Кнопка C                │
         │  Digital 7───┼────┬─── Кнопка D                │
         │  Digital 6───┼────┬─── Кнопка E                │
         │  Digital 5───┼────┬─── Кнопка F                │
         │  Digital 4───┼────┬─── Кнопка G                │
         │  Digital 3───┼────┬─── Кнопка A                │
         │  Digital 2───┼────┬─── Кнопка B                │
         │              │    │                             │
         │  Digital 9───┼────┴─── Кнопка выбора инструмента
         │              │                                  │
         │  GND      ───┼──────────────────────────────────┘
         │              │
         └──────────────┘
```

## Детальная схема кнопок

### Кнопки нот (Digital 2-8):
```
Digital Pin 8 ──┬── Кнопка C ──┬── GND
Digital Pin 7 ──┬── Кнопка D ──┤
Digital Pin 6 ──┬── Кнопка E ──┤
Digital Pin 5 ──┬── Кнопка F ──┤
Digital Pin 4 ──┬── Кнопка G ──┤
Digital Pin 3 ──┬── Кнопка A ──┤
Digital Pin 2 ──┬── Кнопка B ──┴── GND
```

### Кнопка выбора инструмента (Digital 9):
```
Digital Pin 9 ──┬── Кнопка ──┬── GND
```

### Аудио выход (Digital 9):
```
                              +
Digital Pin 9 ──[ 100Ω ]──┬──┤ Динамик (8Ω)
                          │  └─ -
                          │      │
                       [10µF]    │
                    (опционально)│
                          │      │
                         GND ────┘

Или для наушников:

Digital Pin 9 ──[ 220Ω ]──┬── 🎧 Наушники
                          │
                       [10µF]
                          │
                         GND
```

## Примечания

1. **Кнопки:**
   - Используются тактовые кнопки (push buttons)
   - Arduino использует встроенные подтягивающие резисторы (INPUT_PULLUP)
   - Поэтому внешние резисторы НЕ нужны
   - Кнопки подключаются напрямую между пином и GND

2. **Аудио выход:**
   - **Резистор 100 Ом** защищает пин Arduino и ограничивает ток
   - **Конденсатор 10 мкФ** (опционально) убирает постоянную составляющую и улучшает качество звука
   - Для динамиков 8 Ом используйте резистор 100 Ом
   - Для наушников (16-32 Ом) лучше использовать резистор 220 Ом

3. **Библиотека Mozzi:**
   - Генерирует звук через PWM на пине 9
   - Частота аудио: 16384 Гц (высокое качество)
   - Не требует дополнительных компонентов, только Arduino
   - Работает на всех Arduino с ATmega328 (UNO, Nano, Pro Mini)

4. **Тестирование:**
   - Сначала подключите только кнопки и проверьте их работу
   - Затем добавьте аудио выход с резистором
   - Проверьте звук - если тихо, уменьшите резистор
   - Если звук искажен, добавьте конденсатор 10 мкФ

5. **Безопасность:**
   - НЕ подключайте динамик напрямую к пину Arduino без резистора!
   - Максимальный ток пина Arduino - 40 мА
   - Резистор защищает пин от перегрузки

## Альтернативные подключения

### Подключение с усилителем (для лучшего качества):

```
Arduino Pin 9 ──[ 10kΩ ]──┬── Вход усилителя (AUX)
                          │
                       [10µF]
                          │
                         GND
```

Можно использовать дешёвый усилитель PAM8403 или подобный для громкого и качественного звука.

## Выбор резисторов для аудио выхода

Резистор ограничивает громкость и защищает Arduino:

- **47 Ом** - максимальная громкость (будьте осторожны!)
- **100 Ом** - хорошая громкость для динамиков 8 Ом (рекомендуется)
- **220 Ом** - средняя громкость, хорошо для наушников
- **470 Ом** - тихий звук, для тестирования

## Питание

Arduino UNO получает питание через:
- USB кабель (от компьютера) - 5V, 500 мА
- Внешний блок питания 7-12V (через разъём питания)

**Примечание:** Mozzi не требует много энергии. USB питания достаточно для всего проекта.

## Схема макетной платы

```
Макетная плата (вид сверху):

  Arduino UNO
  ┌─────────┐
  │ 2 3 4 5 │  ← Кнопки нот (C D E F)
  │ 6 7 8 9 │  ← Кнопки нот (G A B) + Выбор инструмента
  │   ...   │
  │   GND───┼──── Общий GND для всех кнопок
  │    9────┼──[100Ω]──┬─── + Динамик
  │         │          │
  │   GND───┼──────────┴─── - Динамик
  └─────────┘
```
